# Транслитератор GilyazoV

## Описание проекта

Проект представляет собой транслитератор, который выполняет лексический, синтаксический и семантический анализ исходного кода, а также генерирует промежуточный код.

## Грамматика языка

```
S -> A; D
A -> int L
L -> IX | I
X -> ,I | ,IX
I -> <2>:=<1>
D -> KY | K
Y -> or K | or KY
K -> RZ | R
Z -> and R | and RY
R -> V<V | V>V
V -> <2> | <1>
```

Где:
- `<2>` - идентификатор (начинается с "ad")
- `<1>` - двоичное число (состоит из 0 и 1)

## Структура программы

### Основные компоненты

1. **CLex.cs** - Лексический анализатор
   - Разбивает исходный текст на токены
   - Распознает идентификаторы, числа, ключевые слова (int, or, and)
   - Распознает операторы (:=, <, >, ;, ,)

2. **uSyntAnalyzer.cs** - Синтаксический анализатор
   - Проверяет соответствие кода правилам грамматики
   - Строит синтаксическое дерево разбора
   - Вызывает семантический анализ

3. **Semantic.cs** - Семантический анализатор
   - Проверяет объявление переменных (все используемые переменные должны быть объявлены)
   - Выполняет дополнительные семантические проверки

4. **Translator.cs** - Транслятор в промежуточный код
   - Преобразует синтаксическое дерево в промежуточный код
   - Вычисляет числовые значения выражений
   - Генерирует последовательность команд

5. **TranslationForm.cs** - Форма для отображения кода
   - Показывает исходный код
   - Показывает сгенерированный промежуточный код

## Как работает трансляция

### Процесс трансляции

1. **Объявления переменных (A -> int L)**
   - Обрабатываются все объявления вида `int var := value`
   - Для каждого объявления генерируется команда `MOV var, value`
   - Переменная сохраняется в словаре с ее значением
   - В последовательность команд добавляется "MEM" (операция с памятью)

2. **Выражения (D -> KY | K)**
   - Обрабатываются логические выражения после точки с запятой
   - Выражения могут содержать операции AND и OR

3. **Логические операции**

   **AND (K -> RZ | R, Z -> and R | and RY)**
   - Вычисляется левая часть (R)
   - Если есть Z, вычисляется правая часть
   - Генерируется команда `AND tempVar, leftResult, rightResult`
   - В последовательность добавляется "AND"
   - Результат: `leftResult & rightResult` (побитовое И)

   **OR (Y -> or K | or KY)**
   - Вычисляется левая часть (K)
   - Вычисляется правая часть (K или KY)
   - Генерируется команда `OR tempVar, leftResult, rightResult`
   - В последовательность добавляется "OR"
   - Результат: `leftResult | rightResult` (побитовое ИЛИ)

4. **Сравнения (R -> V<V | V>V)**
   - Вычисляется левое значение (V)
   - Вычисляется правое значение (V)
   - Генерируются команды для сравнения:
     - `SUB tempVar, rightValue, leftValue` (для <)
     - `SUB tempVar, leftValue, rightValue` (для >)
     - `JP labelTrue` (переход, если результат положительный)
     - `MOV tempVar, 0` (если условие ложно)
     - `JMP labelEnd` (безусловный переход)
     - `labelTrue: MOV tempVar, 1` (если условие истинно)
   - В последовательность добавляется "MEM"
   - Результат: 1 если условие истинно, 0 если ложно

5. **Значения (V -> <2> | <1>)**
   - Если это число - преобразуется из двоичного в десятичное
   - Если это идентификатор - значение берется из словаря переменных

### Вычисление числового результата

Числовой результат вычисляется рекурсивно при обходе синтаксического дерева:

1. **Для объявлений (I)**: результат не вычисляется, только сохраняется переменная
2. **Для выражений (D)**: вычисляется результат всего выражения
3. **Для AND (K, Z)**: `result = leftResult & rightResult`
4. **Для OR (Y)**: `result = leftResult | rightResult`
5. **Для сравнений (R)**: `result = (leftValue < rightValue) ? 1 : 0` или `(leftValue > rightValue) ? 1 : 0`
6. **Для значений (V)**: 
   - Если число: преобразуется из двоичного в десятичное
   - Если переменная: берется из словаря

Итоговый результат сохраняется в поле `result` класса `Translator` и возвращается через метод `GetResult()`.

### Последовательность команд

Последовательность команд формируется в процессе трансляции:

- **MEM** - добавляется при операциях с памятью:
  - При объявлении переменных (MOV)
  - При сравнениях (MOV результат сравнения)
  
- **AND** - добавляется при логической операции AND:
  - `AND tempVar, leftResult, rightResult`
  
- **OR** - добавляется при логической операции OR:
  - `OR tempVar, leftResult, rightResult`

Последовательность показывает порядок выполнения операций в промежуточном коде.

## Пример работы

### Исходный код:
```
int ad := 000101110;ad<ad
```

### Процесс трансляции:

1. **Объявление переменной**:
   - `ad := 000101110`
   - Двоичное `000101110` = десятичное `46`
   - Генерируется: `MOV ad, 46`
   - Последовательность: `MEM`

2. **Выражение**:
   - `ad<ad`
   - Левое значение: `ad` = 46
   - Правое значение: `ad` = 46
   - Сравнение: `46 < 46` = false (0)
   - Генерируется:
     ```
     SUB T0, 46, 46
     JP L0
     MOV T0, 0
     JMP L1
     L0:
     MOV T0, 1
     L1:
     ```
   - Последовательность: `MEM, MEM`

3. **Результат**: 0 (ложь)
4. **Последовательность команд**: `MEM, MEM`

### Форма TranslationForm

Форма `TranslationForm` отображает:
- **Слева**: Исходный код (то, что ввели в `tbFSource`)
- **Справа**: Промежуточный код (сгенерированные команды)

Это позволяет сравнить исходный код с результатом трансляции.

## Использование программы

1. Введите код в поле `tbFSource` (например: `int ad := 000101110;ad<ad`)
2. Нажмите кнопку "Проверить"
3. Программа выполнит:
   - Лексический анализ
   - Синтаксический анализ
   - Семантический анализ (проверка объявления переменных)
   - Трансляцию в промежуточный код
4. Появится MessageBox с:
   - Числовым результатом выражения
   - Последовательностью команд (MEM, AND, OR)
5. Откроется форма с исходным и промежуточным кодом

## Проверки

### Контекстное условие: Объявление переменных

Программа проверяет, что все используемые переменные были предварительно объявлены в секции `int L`.

Если переменная используется, но не объявлена, выводится ошибка:
```
Переменная 'имя' используется, но не объявлена!
```

### Убрано условие: Уникальность чисел

Ранее программа проверяла, что все числа в коде уникальны. Это условие было убрано - теперь числа могут повторяться.

## Промежуточный язык

### Команды перемещения
- **MOV** - копирование значения в переменную

### Арифметические команды
- **ADD** - сложение
- **SUB** - вычитание
- **MUL** - умножение
- **DIV** - деление

### Команды перехода
- **JMP** - безусловный переход
- **JZ** - переход по равенству нулю
- **JP** - переход по плюс (если результат положительный)
- **JN** - переход по минус (если результат отрицательный)

### Логические команды
- **AND** - логическое умножение (побитовое И)
- **OR** - логическое сложение (побитовое ИЛИ)
- **NOT** - логическое отрицание

## Технические детали

### Преобразование двоичных чисел

Двоичное число преобразуется в десятичное по формуле:
```
decimal = Σ (bit[i] × 2^(length - 1 - i))
```

Например: `000101110` = 0×2⁸ + 0×2⁷ + 0×2⁶ + 1×2⁵ + 0×2⁴ + 1×2³ + 1×2² + 1×2¹ + 0×2⁰ = 32 + 8 + 4 + 2 = 46

### Временные переменные

При генерации промежуточного кода используются временные переменные вида `T0`, `T1`, `T2` и т.д. для хранения промежуточных результатов.

### Метки

Для организации переходов используются метки вида `L0`, `L1`, `L2` и т.д.
